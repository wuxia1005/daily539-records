# 今彩539 開獎紀錄

手機與電腦皆可使用的繁體中文網頁。從民國114年（2025）1月1日起，持續收錄到官方最新一期，並在開獎時間後向官方資料服務核對更新；跨到116年及以後仍會查詢新年度。

## v1.3 二星、三星、四星搭配統計

- 「二星／三星／四星統計」可切換星數，全部按同一期共同出現、不分順序計算，每組每期最多一次。
- 二星741組、每期計入10組；三星9,139組、每期計入10組；四星82,251組、每期計入5組。
- 可選01～39任一號碼，查看包含它的搭配。二星每碼38組、三星703組、四星8,436組。包含零次組合，次數相同並列名次（例如1、1、3）；列表每次顯示30組。
- 點選組合或最常出現組合，可查看全部出現日期、期別及當期五碼，對應號碼以青綠色標示。
- 統計固定從114年起至最新收錄期別，獨立於開獎紀錄頁的查詢條件。
- 依使用者指定，自動核對只在台灣時間每日20:30後、網頁可見且未收錄當日獎號時執行，每分鐘一次，收到當日資料即停止，跨日後等下一次20:30。其他時段不自動核對，保留手動更新。資料成功通過驗證才同步更新紀錄、統計、排行與已開啟的明細。
- 本機保留最後成功資料；更新失敗時保留原紀錄與統計，並顯示失敗原因及收錄截止日。網站關閉時不在背景更新。

## 資料範圍

初始內附 577 期：114000001（2025-01-01）至115000261（2026-10-28）。截至2026-10-29下午取得的官方資料；115年尚未結束，未開獎期別不會補填。

來源：[台灣彩券今彩539各期獎號與開獎結果](https://www.taiwanlottery.com/lotto/result/daily_cash/)。資料由該頁使用的官方公開 Daily539Result API 取得。每期同時保留大小順序與落球順序。

## 使用

- 查詢年度、月份、日期、完整期別（例如115000261）或年度內期數（例如261）。多項條件同時套用；簡短期別可配合年度篩選。
- 點選1～5個號碼，搜尋同時含這些號碼的紀錄。
- 開獎時間後自動核對，或隨時按「更新官方資料」。更新僅接受完整、期別連續且符合1～39五個不重複號碼的資料；既有期別出現衝突時停止更新並保留原紀錄。
- 網路失敗時仍可查詢原有紀錄。新資料嘗試保存在目前瀏覽器；電腦與手機分別向官方更新。
- CSV下載全部符合條件的紀錄，不限畫面目前顯示的30期。JSON備份全部紀錄。
- iPhone Safari「分享 → 加入主畫面」；Android Chrome「加到主畫面」。不需個人電腦持續開機。
- 更新起點固定為114年，終點隨台灣當日日期推進，不會補猜尚未公布的獎號。未提供預測或投注功能。首次載入需網路，不保證關閉後能離線重開。

## 本機原始專案

在桌面539資料夾直接雙擊index.html，可查詢內附紀錄。需要即時更新時，使用正式HTTPS網址或 `node tools/serve.mjs` 的本機預覽。

```text
node --test tests/*.test.mjs
node tools/prepare-site.mjs
node tools/serve.mjs
```

`tools/download-official.ps1` 可重新下載官方114年起至今的已公布資料，原始回應保存在sources/，正規化資料在data/。本機測試會逐筆比對原始回應。

正式網站使用standalone/index.html單檔封裝（由相同網頁程式與資料產生），另附本說明檔，沒有密碼、個人資料或追蹤程式。來源回應、測試與本機診斷未納入公開目錄。此工具非台灣彩券官方應用程式。
